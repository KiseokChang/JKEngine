# 112 — 데스크톱 위젯 스펙 (2026-11-16)

사용자 제기: *"이전 아이콘들과 자리 겹치면서도 기능이 도는 시계 같은 것들. 이건
Widget 아닌가요?"* — **맞다.** 그동안 셸에 하드코딩돼 있던 우상단 시계는
"위젯"이라는 개념 없이 그려진 1호 위젯이었고, 그래서 아이콘 그리드와 충돌했다.
이 문서는 위젯을 **1급 개념**으로 승격하기 위한 스펙이다.

---

## 1. 정의

> **위젯** = 바탕화면에 상주하며 **스스로 갱신되는 정보/조작 패널**.
> 앱도 아니고(실행 단위 아님), 창도 아니다(타이틀바·포커스 없음).

| 구분 | 실행 단위 | 상태 | 소유 | 예 |
|---|---|---|---|---|
| **앱** | 있음(프로세스/모듈) | 서버가 관리(창) | 클라이언트 | 지뢰찾기, 음악 |
| **아이콘** | 앱을 여는 셀 | 없음(정적) | 셸 | 런처 그리드 |
| **위젯** | 없음(셸 내부) | **자기 갱신 주기**를 가짐 | 셸 | 시계, 상태, 음성 버튼 |

핵심 차이: 아이콘은 **누르면 뭔가 열리고**, 위젯은 **거기서 계속 뭔가 보여준다.**
위젯을 누르면 열릴 수도 있다(시계 → 시계 앱) — 그건 부가 동작이지 정의가 아니다.

## 2. 분류 (v1 범위)

| 유형 | 설명 | 갱신 | v1 |
|---|---|---|---|
| **정보형** | 시계·날짜 — 시간이 흐르면 스스로 변함 | 1초/1분 | ✅ |
| **상태형** | 배터리·네트워크·음성 대기 상태 | 이벤트/폴링 | ✅ (읽기 전용) |
| **동작형** | 음성 버튼·재생 컨트롤처럼 누르면 명령 | 입력 시 | ⏳ v2 |
| **데이터형** | 날씨·일정(외부 소스) | 폴링 | ⏳ v3 (네트워크·권한 판정 필요) |

## 3. 배치 계약 — 아이콘과의 충돌을 구조로 없앤다

**원칙 P-W1: 위젯은 자기 자리를 소유한다.** 아이콘 그리드는 위젯 사각형을
**피해서** 배치된다(위젯이 아이콘을 피하는 게 아니라 반대).

- 위젯은 **정규화 좌표**로 배치한다: `{anchor: top-right, dx, dy, w, h}` — 해상도가
  바뀌어도 같은 의미(폰 세로/DeX 가로 모두).
- 셸은 배치 계산 시 위젯 사각형 목록을 먼저 만들고, 그리드는 **겹치는 셀을
  건너뛴다**(셀 소비 없이 다음 아이콘이 당겨짐). 종전 실패(전폭 밴드 예약)는
  아이콘 전체를 밀어냈다 — 위젯 사각형 단위로만 피한다.
- 위젯끼리 겹치면 **나중 것이 밀려난다**(결정적 순서 = desktop.json 배열 순서).

**원칙 P-W2: 위젯은 포커스를 갖지 않는다.** 키보드·포커스 링 대상 아님. 탭/클릭만
받는다(있을 경우).

## 4. 렌더·갱신 계약

- **경로**: v1은 **셸이 직접 그린다**(SDL 텍스처 + 텍스트 파이프라인). 앱처럼
  클라이언트 표면을 쓰지 않는다 — 프로세스/파이프 비용 없이 상주해야 한다.
- **갱신**: 위젯마다 `refreshSec`(기본 60). 셸은 틱마다 만료된 위젯만 다시 그리고
  `onDynamicDraw(rect)`로 **그 사각형만** 더티 처리한다(전체 재드로잉 금지).
- **텍스트**: `p/10foot-type` 가드 준수 — 본문 ≥ 22sp 상당, 외곽선(대비) 적용.
- **테마**: 색은 테마 토큰(`widgetText`/`widgetBg` 신설 예정). 색이 텍스처에
  베이크되므로 세대 변화 시 캐시 무효화 대상(기존 라벨과 동일 계약).

## 5. 상태·영속

`state/desktop.json`:

```json
{
  "showDev": false,
  "widgets": [
    { "type": "clock",  "anchor": "top-right", "dx": -20, "dy": 20, "w": 220, "h": 90 },
    { "type": "status", "anchor": "top-left",  "dx": 20,  "dy": 20, "w": 180, "h": 40 }
  ]
}
```

- 파일이 없거나 `widgets` 부재 = **기본 세트**(clock 1개) — 첫 실행에서도 보인다.
- 잘못된 값(모르는 type/크기 0) = 그 항목만 무시(정직 열화 — 전체 실패 금지).

## 6. 상호작용

| 위젯 | 클릭 | 비고 |
|---|---|---|
| clock | 시계 앱 열기(`시계 켜줘` → `clock`) | 트레이 시계 클릭과 같은 채널 |
| status | 상태판(창 목록) 표시 | 오버레이 ≡ 버튼과 동일 동작 |

- 클릭 판정은 위젯 사각형 히트테스트 — 셸의 기존 마우스 경로에 한 분기 추가.
- 위젯 클릭이 **아이콘 실행으로 새지 않게** 히트 순서: 위젯 → 아이콘.

## 7. MVP 범위 (이번 구현)

1. 셸에 `Widgets` 목록 + `state/desktop.json` 로더(기본 clock 1개)
2. clock 위젯: 시:분 + 날짜, 1분 갱신, top-right 정규화 배치
3. 아이콘 그리드 = 위젯 사각형 회피(셀 스킵)
4. clock 클릭 → 시계 앱(이미 만든 `jkapp_clock`)
5. 테마 토큰 2개(`widgetText`, `widgetBg`)

**비목표**: 스크립트 위젯, 원격 데이터(날씨/일정), 애니메이션, 드래그 재배치.
이들은 v2 이후 — 배치 계약(§3)이 그대로 확장점이 된다.

## 8. 검증(종료 조건)

- 위젯과 아이콘이 **겹치지 않는다**(임의 해상도 3종: 폰 세로·DeX 가로·PC).
- 시계가 **1분마다** 갱신되고, 갱신 시 **그 사각형만** 더티 처리된다(로그).
- 위젯 클릭 → 시계 앱이 뜬다(폰 실측).
- `showDev` 토글과 **상호 간섭 없음**(상태 파일 단일, 키 분리).
