# 67. 워크숍 대형 — "말로 만드는 앱"에서 앱 생태계까지 (비전 원장)

> 날짜: 2026-09-26. 계기: O1 한자 종결(docs/66) 후 사용자가 워크숍 축 선택 —
> "개발 환경이죠?", "저장·합성 되죠?", "내 플랫폼·언어로 포팅도 가능하겠네요",
> "스크립트 개발환경 사훈 가져올 것 없을까요". 실행 플랜 아님 — **방향 원장**.
> 각 단 착수 시 별도 플랜(승인 절차 유지).

## 1. 한 줄 그림

워크숍을 관문으로 하는 앱 공장 — **작업대 품격 → 출하·나눔 → SDK 계약(P4) →
제2의 해석기(포팅)** 4단 사다리. 나눔 앞에 트러스트 문. 폐곡선(LLM 자기교정
루프)이 모든 단의 심장.

## 2. 지금 서 있는 곳 (2026-09-26)

- 워크숍 v1(docs/60): 슬롯 1개(myapp.js), 폐곡선(set_script→동기 리로드→에러
  귀환, §4 c3 실증), 캔버스 API v5(§10), declareCursor(§13), api 카탈로그(§8),
  mtime 핫 리로드, 테마 핫스왑(docs/52), jkbridge 폰 게이트웨이(docs/57).
- 패키지: .jkx 컨테이너. 단 jkctl pack은 **MANI를 재생성해 신필드 탈락**
  (docs/60 §6 — "pack 도구가 MANI 화이트리스트"라는 설계 결함, 워크숍은 수기
  패커로 우회 중).
- 이미 확정된 방향: **P4 앱 SDK 계약화**(docs/43, 사용자 확정), 의미 커서(docs/64).
- 자세: 프로토타입 — 트러스트 배제(docs/60 헤더).
- 대형 잔여(docs/60 §5): 복수 슬롯 / 폰 미러 / 보안·트러스트 재검토.

## 3. 남의 환경에서 가져올 것 (사훈 5 — 2026-09-26 대화)

| # | 사훈 | 원본 | 워크숍에 적용하면 |
|---|---|---|---|
| 1 | **상태 보존 핫 리로드** | React Fast Refresh / Erlang 핫 코드 | 지금 리로드=Stop+재시작이라 앱 상태 증발(에디트 텍스트·타이머·카운터). QuickJS 컨텍스트를 살린 채 정의만 재평가하는 라이브 패치 — "말로 고치는" 체감을 바꾸는 1순위 |
| 2 | **버전 리본+타임트래블** | Elm 디버거 / Jupyter 셀 히스토리 | set_script 1회=1세대. 스냅샷+diff+롤백. myapp.js 덮어쓴 사고(docs/60 §10.2)가 안전장치 근거. "3번 전 버전으로"의 인프라 |
| 3 | **위젯→코드 점프** | HyperCard (실행물=편집기 한 몸) | 실행 중 위젯 클릭 → 만든 코드 줄로. 폰 미러와 결합하면 **지적=프롬프트** |
| 4 | **반응형 결속** | Excel / Elm 아키텍처 | createButton+onClick+setText 명령형 배선은 LLM 실수 보일러플레이트. `bind(label, () => state.count)` 1줄로 배선 버그 클래스 소각 — 계약 v2 후보 |
| 5 | **공유·갤러리** | Roblox Studio / Scratch 커뮤니티 | 만든 것의 출하+보여주기. **슬롯=공유 단위**로 설계해두면 단 2에서 공짜 |

안 가져가는 것: 블록 편집(Scratch류) — 문법 오류를 구조로 막는 아이디어는 LLM
작성자에게 무의미. 텍스트가 LLM과의 접점.

## 4. 4단 사다리 (단마다 사용자 눈에 보이는 가치 1개)

### 단 1 — 작업대의 품격 (복수 슬롯 + 사훈 1·2)
- **복수 슬롯**: `state/scripts/<slot>.js`, 슬롯 목록 UI, get/set_script에 slot
  인자. 슬롯=공유 단위(사훈 5 예약).
- **버전 리본**: 세대 스냅샷+diff+롤백. 스냅샷도 평범한 파일(원칙 1).
- **상태 보존 리로드**: QuickJS 컨텍스트 생존+정의 재평가. **게이트: 리로드 전후
  상태 동일성 체크**(에디트 텍스트 생존) 없이 착수 금지. 실패 폴백 = 앱 계약
  setState/getState 직렬화.
- **폰 미러**: 감독 자리를 폰으로 — jkbridge 세션 모델에 얹는다(새 채널 금지).
  사훈 3의 지적=프롬프트는 이후 여지. — **사용자 결정: 다음 리파인으로 연기
  (2026-09-26)**

#### 단 1 as-built (2026-09-26)

**완결**: 복수 슬롯+버전 리본+상태 보존 리로드(폴백 경로). 커밋
106f481(JKWorkshopStore)→66f2bce(호스트 상태 API)→d7a3edb(통합 리로드)→
93126e8(슬롯 도구+리본)→09abfb5(스트립 UI)→ab289a2(유닛 프로브)→47746da
(라이브 게이트).

- **카탈로그 3→7 도구**: get_script/set_script(slot 인자=쓰고 자동 전환)/
  list_slots/use_slot/script_history/restore_script(복원 자체 undoable —
  직전 원문이 새 세대)/api. 서버·와이어·jkagentd 무수정(app_tool 중계가
  generic이라 신도구가 무수정 통과 — §5 원칙 3 실증).
- **버전 리본**: `<scriptsDir>\.history\<slot>\NNNN.js`(4자리, 20세대 캡

  v1 리본 우회 — 감시 경로는 도구 쓰기와 손쓰기 구분 불가, **문서화 한계**
  (콘텐츠 해시 대조는 필요 시 후속). diff는 미구현(세대 원문은 왕복 가능 —
  diff는 단 2 출하 전 여지).
- **상태 보존 = 폴백 경로 완성, 라이브 패치는 잔여**: 리로드는 여전히 컨텍스트
  폐기(Stop+Start)지만 캡처→복원이 이제 기본 동작 — ①위젯(JKEdit 텍스트
  KSSM↔UTF-8+입력모드, 편집창 생성순서 접두 매칭, 양쪽 다
  "[script] state restore: n/m edits" 로그) ②JS `onSaveState()`/`onRestoreState`
  (계약 원문은 scripts/jk.d.ts v6+api 카탈로그 "state" 필드). 라벨·캔버스=
  스크립트 소유 파생 출력(복원 금지 — 새 스크립트가 다시 그린다). 상태는
  `stateByPath_` 인메모리(리로드 간 수송 수단일 뿐 진실 아님 — 원칙 1) —
  **슬롯 전환은 상태를 공짜로 보존**(구 경로 키에 보관, 복귀에 복원).
  불변 = pending 1건 ↔ Start 1회(적재는 Start 직전 항상, Start 서두 클리어
  금지 — 유닛 프로브 c4 실측).

  점프)·사훈 4(반응형 결속) — 후자 2건은 계약 v2(단 3) 예약 자리 유지.

### 단 2 — 출하·나눔 (앞에 트러스트 문)
- **트러스트 문(선결)**: 워크숍 무승인 경계 명문화 + 배포 트러스트 모델. 후보 =
  능력(capability) 선언형 — manifest가 쓰는 API를 선언, 엔진이 게이트.
  permissions.json 런타임 파일 선례. **설계 필요, 사용자 결정.**
- **jkctl pack 뿌리 수리**: MANI 화이트리스트 설계 → 필드 보존으로. 이 수리 전에
  슬롯 출하 도구를 만들면 결함 재생산.
- **슬롯→.jkx 출하** 도구. 갤러리(설치 앱 목록)는 로컬 라이브러리만.

### 단 3 — SDK 계약 고정 (P4, docs/43)
- 스크립트 API를 **버전 붙은 계약**으로: 위젯+타이머+캔버스(v5)+에이전트 훅
  (declareCursor/onAgentAct/onSnapshot)+라이프사이클.
- 사훈 4 반응형 결속(bind)은 **계약 v2**로 흡수 — 첫날부터 버전을 붙이는 게
  포팅의 전제.
- 적합성 테스트 = 기존 probe 패턴(×2 원칙) 그대로 승계.

### 단 4 — 제2의 해석기 (포팅)
- 첫 목표 **1개로 압축: 웹 호스트** — 브라우저가 같은 계약을 DOM으로 구현.
- **포팅 루프 = 워크숍 폐곡선의 일반화**: 번역→새 호스트 실행→에러 귀환→자기교정.
- 의미 커서(docs/64)가 여행한다 — 앱은 의도 층 계약이므로 해석기만 바뀜.
- 재디자인은 이미 공짜(테마 핫스왑+LLM 소스 재작성) — 단 4에 포함 없음.
- 언어 포팅은 LLM 번역 루프로 같은 원리 — v1 범위 밖, 기록만.

## 5. 설계 원칙 (부술 수 없는 것)

1. **파일=진실원** — 슬롯·세대·설정 전부 평범한 파일. 숨은 DB 금지. 포팅과
   디버깅이 공짜가 되는 근원.
2. **선언하라, 그리지 말라** — 앱은 의도만, 해석은 엔진 몫. 재디자인·포팅을
   값싸게 만드는 근원.
3. **폐곡선을 깨지 말라** — 신기능 채택 조건: 에러가 LLM에게 돌아오는 루프
   보존. 버전 리본도 사훈 1도 루프를 강화하는지로 판정.
4. **프로토타입 자세는 트러스트 문 앞까지만** — 나눔이 시작되면 자세 종료.

## 6. 위험

- 라이브 패치는 풀 리로드 대비 복잡도가 큼 — 게이트(§4 단 1) 없이 착수 금지.
- 계약 동결 시점: 이르면 후회, 늦으면 포팅 이중 수리 — **단 1 끝난 뒤**가 적기.
- 폰 미러를 새 채널로 만들면 jkbridge 이중화 — 세션 모델 얹기만.
- MANI 화이트리스트 수리 전 출하 도구 제작 금지(결함 재생산, docs/60 §6).
- 트러스트 모델 없는 나눔 — 단 2의 문은 장식이 아니라 관문.

## 7. 열린 질문 (사용자 결정 시점)

1. 트러스트 모델 형태 — 능력 선언형 / 서명 / 검수.
2. 첫 포팅 목표가 웹이 맞는지.
3. 갤러리 범위 — 로컬 라이브러리만? 외부 공유는 언제?
