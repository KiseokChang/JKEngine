# 스펙 — jkdesktop 네비게이션 체계 (2026-11-08)

동기(사용자 원존): "브라우저 상태→바탕화면 어떻게 가죠?" + "태스크 바에 백 키·
홈키·메뉴키가 있어야 라지 않을까요" + "네비게이션 체계를 정리할 필요". 지금까지
개별 leg가 흩어져 쌓였다 — 본 스펙이 유일 원장이고, 구현은 이 표 소관 순서로.

## 1. 표면 4층 (위에서 아래로)

| 층 | 실체 | 네비 수단 |
|---|---|---|
| L1 오버레이 액티비티 | 브라우저(BrowserActivity — 창 서버 밖) | 주소행·뒤/앞/새고·Go·측정·BACK 키·(구두) |
| L2 바탕화면(셸) | DeX 표면 2 전면 — 아이콘 그리드 | 셀 탭(앱 개봉)·(구두)·DeX 홈 JK 아이콘(부트/복구 한 탭) |
| L3 엔진 창(앱) | libjkc 표면(태스크바 버튼과 1:1) | 태스크바·창 번호 화법("창 3 앞으로")·(구두) |
| L4 폰 컨트롤 앱 | 독립 APK(chg.jkcontrol) | MIC 구두·START DEX·BACK/(구두)·BROWSER |

## 2. 네비 3종의 의미 고정 (1표 1의미 계약)

| 지시 | 의미 | 라인 |
|---|---|---|
| **홈(HOME)** | "바탕화면 상태로" — 오버레이(L1)를 치우고 L1 아래 층이 드러난다. 브라우저 = 닫기, 이 후 창 전체화면(vplayer 등)은 v2 | AmpkClose(어휘 "바탕화면으로" — 원존) |
| **뒤(BACK)** | 맥락 단계 전진 복귀: 브라우저 = 웹 히스토리 뒤로(새 leg AmpkBack). 엔진 창 = v1 제외(의미 부재 — 정직 보류) | AmpkBack(신설) |
| **앞(FORWARD)** | 브라우저 웹 앞으로 — 신설 AmpkFwd(BACK 동형 — 이번에 함께 봉입) | AmpkFwd(신설) |
| **메뉴(MENU)** | v1 제외(사유: 메뉴가 정의할 도메인 대상 부재 — 앱 메뉴 체계 미성립). 후보 = 창 목록 오버레이 재용(기존 "창 목록"·overlay_numbers 계열) — 사용자 판쓴 대기 | — |

## 3. 수단 채널 (어디서 누르든 같은 뜻)

모든 수단이 **라우터 exact 행 1개**를 공유한다(1표 1의미):

```
구두(STT) ─┐
폰 컨트롤 앱 ─┤→ POST :8091/talk {"text":"..."} → ChatRouter exact → jkweb 훅 →
태스크바 셀 ─┘                                        브라우저 브로드캐스트(닫기/뒤/앞)
TV BACK 키 ──→ BrowserActivity onBackPressed(히스토리→복귀 — 플랫폼 계약)
```
- 태스크바 셀(홈·뒤) = 태스크바 자식 프로세스가 :8091/talk로 직행 POST
  (jk::net — 같은 폰 루프백; UI 스레드 블록 금지 — 워커 스레드 단발).
- 컨트롤 앱 BACK 버튼 = "바탕화면으로" 지시(앱 단독 keyevent 주입 불가 —
  시스템 권한 — 원존). 뒤 키 주입은 폰 앱으로는 성립 불가 — 채널 위로.
- 수면 함정 원존: TV OFF·폰 Dozing 상태 부팅 = SDL surface 미성립 —
  이 체계의 모든 실측은 화면 켜진 상태 기준.

## 4. 신설 라인 (본 스펙 1차 구현 범위)

1. AmpkBack·AmpkFwd kind — AmpkClose 동형(enum 꼬리·계보 보존): exact 행
   "브라우저 뒤로"/"브라우저 앞으로"(+STT 변형 2종), jkweb 훅 →
   BrowserActivity 브로드캐스트 ACTION_BACK/ACTION_FWD → onReceive = 웹 뒤/앞.
2. 태스크바 네비 셀 — 홈·뒤 2셀(좌측 고정폭): 홈 = talk("바탕화면으로"),
   뒤 = talk("브라우저 뒤로"). 창 버튼은 네비 셀 우측으로 미끼침.
3. 컨트롤 앱 BACK 버튼 = talk("바탕화면으로") — (이미 수형 중).
4. 메뉴 = v1 제외(§2) — 사용자 판쓴 대기.

## 5. 검증

- PC: selftest(1n-v 확장)·jktalk --route 어휘 원문.
- 폰: TV에서 태스크바 셀 탭 → 브라우저 반응 원문(srv.err)+캡처.
- 실패 회신 = Info 폴백(가짜 성공 없음 — 상존 계약).
