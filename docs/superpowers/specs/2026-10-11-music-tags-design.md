## 목적

music 목록을 파일명이 아니라 **곡명·아티스트·앨범**으로 보여준다 —
#92 D2(파일명 스캔 v1)의 2단계. 파일이 곡명을 갖는다(태그)는 게
음악의 정의라는 것 이외의 이유 없음(DRY 최소).

## 결정 원장 (컨트롤러 재량)

- **D1 조달 = zero**: 외부 라이브러리 조달 금지(원칙). 파서는
  **own 순수 부품`(jk::music::tags)`+조달된 third_party의 내장 메타
  API 재용** — dr_flac(FLAC vorbis 코멘트)·stb_vorbis(Ogg)·dr_wav/
  dr_mp3 — **which API가 실제로 그리고 이들의 갭을 own ID3v2 파서로
  보완하는지 T1에서 실측**. ID3v2.3/2.4 텍스트 프레임(TIT2/TPE1/
  TALB/TDRC/TRCK)+ID3v1 폴백+나머지 포맷은 third_party API에 의존.
- **D2 스캔 1패스**: 태그 파싱은 스캔 워커에서 진행(헤더 — 헤더만
  읽는 것·전체 파일 열지 않고 앞부분/메타 영역만·취급의 정의) —
  별도 워커/단계 없음. 파싱 실패=태그 빈+오류 원문 표기 없음(파일명
  폴백이 정상 경로).
- **D3 Track 확장**: `Track`에 `title/artist/album`(UTF-8 규약 — #94)
  +fallback 규약: title 부재=파일명(확장자 제거)·artist/album 부재=
  "-" 표기.
- **D4 UI**: 열 재편 — [곡명(아티스트)] [앨범] [크기] [수정] —
  가독 우선·[spatial]/더블클릭 배선 원존 무변조. **정렬 변경 없음**
  (v1: mtime desc 고정 — 정렬 표기가 UI 갈피).
- **D5 필터 확장**: MatchFilter를 곡명/아티스트에도 매치(v1·파일명
  매치 원존 유지) — 검색이 파일명만이면 태그로 보는 의미가 절반.
- **D6 폰/WSL 규약 동일** — selftest 2s(합성 원문)로 양축.

## 1. 파싱 설계

- **ID3v2:** 헤더 10B(ID3·ver·flags·size syncsafe)+프레임 10B 헤더
  (TIT2/TPE1/TALB/TDRC/TRCK)+텍스트 인코딩 바이트(0=ISO-8859-1·
  3=UTF-8 — **1/2(UTF-16/BOM)은 v1 = UTF-16LE로만 확장·BOM 무시
  실패 시 skip**)+unsynchronisation/padding 스킵·footer(0x3DE) 처리.
  size syncsafe 정확성이 검증의 대부분.
- **ID3v1:** 말미 128B("TAG"+30/30/30) — v2에서 못 찾으면.
- **FLAC/Ogg:** third_party 메타 API(실측) — own 파서와 같은 Track
  필드로 정규화.
- **UTF-8 규약(#94):** 어떤 인코딩이든 파서에서 UTF-8로 정규화해
  Track에 기록(ISO-8859-1 = 바이트 그대로(사실상 Latin-1 = UTF-8
  승격 — 코드 변환 함수·CP949 아님 — 원장)).

## 2. UI/도구 계약

- 도구 6종 원존 무변조 — **music_dir_list 불변**(태그를 나열하지 않는다
  — probe가 별도 측정: 새 도구 없이 트랙 표기 원문 캡처).
- idle 계약(#89) — 파싱은 워커 몫·도착 표기만 더디.

## 3. 테스트

- **selftest 2s:** ①ID3v2.4 합성 원문(TIT2/TPE1/TALB — UTF-8) ②v2.3
  (ISO-8859-1 한 곡 — Latin-1 승격 원문) ③v1 폴백 ④syncsafe 산수
  (2^28 경계) ⑤FLAC 합성(리얼 메타 없이 합성 어림 불가 — **flac 실측
  원문 = T1에서** 합성 파일 1건(engine 소유·임시) ⑥Ogg 합성 ⑦매치
  확장 4건 ⑧fallback 규약 — **2s ~12건**.
- WSL probe: 합성 태그 트랙 → 목록 열 표기 원문 1행+필터 원문.
- 폰 probe: 캐논 흡수(2s n)+표기 원문.

## 4. 성공 판정

- selftest 2s 전축 + WSL 실측 + 폰 캐논 등호 — 사용자 육안(WSL/Win
  태그 목록·정렬·필터 체감) = EYES.
- 캐논 계보 표기(2s n — 기존 4축 등호 유지).
