# 스펙: POSIX 텍스트 스케일 수리 — 기하만 커지는 글리프 배선 (2026-10-09)

발단(docs/85 원장 후속, 사용자 폰 육안 결제 직후 관측 2026-10-09): 폰
settings.json `text.font_scale=1.9` 시험 — **셀 기하만 1.9배로 커지고
글리프 픽셀은 무변**(비트맵 폴백 고정 8x8/8x16) → 제목 클립·버튼 라벨 버튼
밖 밀려남("위치만 위쪽으로 바뀌었어요"). A/B 캡처(desk_s10/desk_s19,
ffmpeg x11grab)로 단정. 1.0 복원 완료.

실측 정리(스펙 착수 진단 2026-10-09):
- 서버 크롬(창 제목 밴드·승인 배너) 텍스트 = **설계상 비트맵**
  (원문: "크롬 타이틀과 동일한 글리프 경로 — Utf8ToKssm + JKDC 비트맵
  폰트… 새 글리프 엔진 없음", docs 원장 app-tool-hub §5).
- 서버 셸 툴팁은 font_scale이 **정상 적용됨**(툴팁 텍스처 'Minesweeper'
  175x40 = 1.9 메트릭 반영) — 서버 측 아틀라스 경로는 살아 있음.
- 클라 모듈(지뢰찾기 패널·숫자·터미널 셀)은 벡터 아틀라스 설치 코드가
  존재(JKClientApplication.cpp:195-206)하고 폰트 경고도 0(=Init 성공
  정전)인데 글리프가 비트맵으로 그려짐 — **DrawGlyph 실패 → 비트맵 폴백**
  또는 결선 누락 어딘가. 경고가 조용히 죽는(비계측) 것이 결함의 일부.
- Windows 전체 벡터 정상 — 결함은 posix 한정 가설(T1이 단정).

## 목표

폰(posix)에서 텍스트가 `text.font_scale`을 **글리프 스스로** 따라한다 —
기본 배율을 켜지 않아도(키 삭제 상태) 폰 데스크톱 텍스트가 기본 배율에서
읽히는 크기가 되고, 배율을 올리면 글자 픽셀도 커진다.

**기본 배율 결정(사용자 확정 2026-10-09): POSIX 기본 `font_scale` = 1.5**
(settings.json 미설정 상태의 소자 기본; Windows는 1.0 유지 — docs/78
"Windows·WSL은 ACCELERATED 유지" 원칙의 윈도 무변 승계). 폰/WSL 데스크톱
전체(클라 앱 UI·터미널 셀·크롬 타이틀)가 이 기본을 따른다.

## 설계 결정 (사용자 답변 반영 — 컨트롤러 룰링)

1. **범위 = 클라 글리프 결선 수리 + 비트맵 폴백 셀 확대 + 크롬 타이틀
   밴드 개선. 크롬 벡터화 불포함(사용자 확정)** — "새 글리프 엔진 없음"
   설계 원문 존중; 타이틀은 기존 비트맵 경로에서 **밴드 높이·글자 크기를
   셀 메트릭 연동으로 확대**(비트맵 글리프를 타이틀 밴드 크기로 블릿
   스케일 — 엔진 신설 아님).
2. **근원 규명 선행(T1, Iron Law)** — 클라 DrawGlyph가 왜 실패/비봉인
   (비계측: 경고 0건)을 코드 원문으로 확정하고 결선 지점을 표 1건으로
   기록한다. 추측 수리 금지.
3. **수리 배선(T2)**: ①클라 모듈·터미널 텍스트 그리기가 셀 메트릭을 실제
   따르도록(1순위 기존 벡터 아틀라스 결선 — Windows와 동일 경로) ②실패
   폴백 = 비트맵 글리프를 셀 크기에 맞춰 확대(blit — 현재는 고정 픽셀로
   그대로 그음; nearest 확대, fail-safe).
4. **콘솔(폰트 경고) 실패의 가시화** — 아틀라스 Init 실패·미결선은 경고
   1회(stderr)로 잡는다(재시도 스팸 없음 — 배너 선례).
5. **측정 계약** — 폰 font_scale 1.5(기본) 캡처 A/B(1.0 강제
   JK_TEXT_SCALE?=불요 — settings로), 지뢰찾기 제목·버튼·숫자 실측,
   사용자 육안 결제가 최종 관문.

## 검증 계약

- selftest: ComputeCellMetrics/글리프 확대 관련 순수 파트(신설 케이스
  있으면 캐논 계보 기록 — 현 Win 518/WSL 495/posix 226/폰 495).
- WSL 실측: posix 공통/폰 특유 판정(T1) — WSL 클라 텍스트가 벡터로 나오면
  폰 특유(폰트 파일/환경) 원장.
- 폰 실측: 기본 1.5 상태에서 클라 앱 텍스트 실제 커짐 캡처(A/B) + 크롬
  타이틀 밴드 개선 확인 — **사용자 육안 결제가 최종 관문**(가짜 결제 금지).
- Windows 무회귀: selftest 캐논 유지 + Windows 기본 배율 1.0 유지.
