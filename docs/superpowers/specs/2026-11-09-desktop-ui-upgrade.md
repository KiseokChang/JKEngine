# 스펙 — 데스크탑 UI 재검토·업그레이드 (2026-11-09)

동기: 사용자 원존 "태스크바 포함 데스크탑의 사용자 인터페이스를 재검토하고
업그레이드 하자". 실물 캡처(TV 1920x1080 — ui_audit.* 원존) 기준 감사.

## 0. 현실 레이어 (DeX 표면 스택 — 원존)

1. **엔진 바탕화면**: 벽지 사진 + 런처 그리드(아이콘 64px·라벨 0 — 뜻은
   호버 툴팁만) — 행 높이 80px·셀 100px 간격.
2. **엔진 태스크바**(하단 40px): 창 버튼(칩+제목 — 한글 라벨 클립 실측
   결함) + 네비 셀 뒤/홈/최근(42px 글리프 — 라벨 클립).
3. **삼성 DeX 시스템 바**(맨 하단 — Samsung 소유: 뒤·홈·최근·앱서랍·검색):
   우리 소관 아님(관례 승계 — 스펙 11-08 §2).

## 2. 상향 그레이드 항목 (순서 = 체감 효율)

**U1 런처 셀 업그레이드(라벨+크기)** — A1·A2: 셀 = 아이콘 80px + 이름 라벨
(셸 벡터 폰트 — KSSM 승계·호버 강조 유지), 행 간격 여유. 30셀 2-3행 배치.

**U2 태스크바 창 버튼 수형(라벨 클립·활성 강조)** — A3: 칩 제거(라운드
미니 아이콘 1개로 요약)·제목 자동 축약·활성=밝은 면+굵은 테두리(토큰 원존).

**U3 시계·상태 표시(태스크바 우측 고정)** — A5: HH:MM(벡터 폰트)+구두/mic
상태 점(청안: 들고 있는 동안만). 시계 = 태스크바 자식의 1초 무효 다시그리기
(다이너믹 드로잉 사건 경계 — onDynamicDraw 원존 재용).

**U4 네비 셀 라벨 클립 수형** — A6: 아이콘+라벨 2단 구성(셀 48x40)·또는
호버 툴팁(런처 툴팁 기계 재용).

**U5 폰트 스케일 적용(DeX 1.2배 기본)** — A4: cfg 폰트 스케일 leg 존재 재용
(설정 앱 계열) — 전 UI 일괄 확대.

**U6 정렬·정리 진입점** — A7: 태스크바 우측 "정리" 셀 = save_layout 트리거
(도구 0 신설 — 클라 POST leg 재용).

- S4 시계 위젯(바탕화면 우상단 큰 시계 — 위젯 레이어 v0).
- S5 정리 셀(태스크바) = save_layout 트리거(POST :8091/talk 재용 —
  "창 정리해줘" 어휘 신설 필요 판정 — 도구 leg 존재 확인 후).
