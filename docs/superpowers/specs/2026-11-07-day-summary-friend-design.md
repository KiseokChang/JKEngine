# 하루 정리 친구 — 스펙 초고 (2026-11-07 — 사용자 백로그 원문: 11-04 말미)

## 1. 문장

"폰으로 무선 DeX 연결해서 폰으로 목소리로 제어하면서 작업하고, 그 결과를
가져다 다시 업데이트하는 싸이클"의 종료 단계 — **하루를 마무리하는 대화**.
제어 에이전트가 아니라 **회고 파트너**: 오늘 있었던 일을 기록·공유·정리한다.

## 2. 입력 원존 (이미 수집 중인 것)

1. 대화 세션 기록 — `state/dialogue/<YYYYMMDD-HHMMSS>_<source>_<id4>.jsonl`
   (스펙 docs/superpowers/specs/2026-11-01-chat-session-log-design.md —
   웹·구독·APK chat 3표면 통일 원문).
2. 사용 저널 — `use_journal.jsonl` (도구 1콜 1행 — 수확 probe
   jkharvest.sh 원존).
3. 원장 문서 — docs/*의 갱신(커밋 메시지의 "갱신 N" 헤더 행 파스 가능).
4. 폰에서의 음성 인식 결과(구두 턴 원문) — 같은 dialogue 채널.

## 3. 표면

- 채팅(구두+문어 동일)의 신설 어휘: **"오늘 정리해줘"** — exact 행 1행 추가
  (라우터 표 문화 원존 — 어휘 2본 금지 계약과 같은 1행 철학).
- 동작: 오늘의 세션 기록+저널을 수취 → 회고 턴(LLM — 기존 엔진 계약) →
  3부 구성(①한 일 ②남은 것 ③내일 추천)을 채팅으로 회신+TTS 발화.
- 정적 안전: 쓰기 = 없음(읽기 전용 — 세션 파일은 기존 채널이 이미 쓰는 것).
- 파일 산출(선택): `state/dialogue/daylog_<YYYYMMDD>.md` — 마지막 회신의
  사본(앱이 쓰는 것 — 서버 권한 계약 준수).

## 4. 비-목표 (v1)

- 예약(스케줄 자동 실행) — v2. 수동 발화만.
- 감정 분석·요약 톤 제어 — 모델 원존.
- PC 어디서든 원격 턴 — cloud/relay 계약 승계.

## 5. 구현 골격 (예상)

- ChatRouter: exact 행 1개(`"오늘 정리해줘"` → DaySummary kind 신설 —
  enum 말미 배치 — 와이어 상호호환).
- 파서: 3파일 리더(오늘 날짜 필터) — 순수 부품+셀프테스트.
- 엔진: 기존 TurnSync 재용(스폰 leg와 HTTP leg 전부) — 신규 스폰 0.
- APK: 구두 표면은 기존 [구두] 계약 무접촉 — 채팅으로 회신되면 TTS가
  자동으로 발화하는 것도 기존 파이프.
