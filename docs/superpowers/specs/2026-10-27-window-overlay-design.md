## 목적

구두로 쉘의 창을 누르는 두 번째 방식 — "창이 여러 개일 때 앱명으로 못 지시하는
상황"(같은 앱 2개·이름 모르는 창)에서 **"창 번호 보여줘"** → 각 창에 번호 라벨
오버레이 → **"창 3"** → 해당 창 포커스(그리고 구두 후속 조작 대상).

  z-order 순서 = list_windows 등호 — 결정론). **창 내부 요소 그리드 = v2**
