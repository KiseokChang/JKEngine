# 갤러리 앱 (#82) 구현 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사진 모아보기 허브 `gallery` 모듈 신설 — 썸네일 격자 + 전체 보기(이전/다음) + state/screenshots + settings `gallery.dirs` 폴더, 썸네일 디스크 캐시.

**Architecture:** 신규 공유 모듈 `jkapp_gallery`(shot 선례 — jk_app_meta/jk_app_run_client C ABI, ImGui 루트창 16ms 타이머) + 두 뷰 모드(격자/전체보기)를 한 ClientGalleryApp 상태머신으로. 이미지 디코드=LoadImageFile(stb_image), 썸네일=full 디코드→nearest 박스 축소→PNG 디스크 캐시(stbi_write, 키=경로+size+mtime FNV-1a), 메모리 텍스처 풀 LRU. 폴더 소스=settings.json `gallery.dirs` 배열(기본=state/screenshots).

**Tech Stack:** C++ (jkclient JKDC/ImGui 루트창 idiom, apps/JKAppModule C ABI), std::filesystem(ec 중립형), stb_image/stbi_write, selftest 쌍둥이(engine/src/main.cpp + posix_selftest/main.cpp), bash probes(WSL+폰 x11grab).

**Spec:** docs/superpowers/specs/2026-10-09-gallery-design.md
