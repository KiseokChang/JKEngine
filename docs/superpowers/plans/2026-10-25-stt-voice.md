# STT 구두 v1 (#112) 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** 말(push-to-talk) → whisper.cpp 로컬 전사 → 기존 자연어 파이프라인(chat)으로 OS 조작+문자 대화 — Win·폰(DeX) 양축, 네트워크 불요 폰 단독 완결.

**Architecture:** whisper.cpp 소스 vendor(third_party — imgui 선형)+`whisper-cli` 별도 프로세스 스폰(WHISPER_ROOT fail-closed — spatial-player/ollama-direct 선형)+ggml 모델 무추적(조달기 스크립트만 커밋)+접점은 in-process `ChatRouteTurn` 직호출(신규 파서 0 — "STT 텍스트==타이핑 텍스트").

**Spec:** docs/superpowers/specs/2026-10-25-stt-voice-design.md (확정 — 사용자 결정 2건+R1-R5 재량 폐곡)

## Global Constraints

- 조달 규약: whisper.cpp **소스만** third_party 커밋(imgui 선형 — 예제/문서/모델 폐기)·ggml 모델+whisper-cli 바이너리 = **무추적**(조달기 스크립트만 커밋 — "기계만 커밋" 원칙 docs/81/84)·클라우드 STT 금지.
- fail-closed 원존: WHISPER_ROOT(또는 state 설정 키) 미설정/바이너리 부재/모델 부재 = 구두 leg **끔+정직 표기** — 나머지 시스템 무영향(spatial leg 원존 계약 승계).
- 전사 비결정 원칙: selftest는 **순수 부품+fail-closed 판정부만 단정** — 전사 본문 단정 금지(2v 계보·CANON 밖 probe 캡처+EYES 승계).
- 무음 계약: vplayer 조그 무음(갱신 60 원존) 무변조·녹음=별 장치/별 세션(Win WASAPI 공유·폰 Termux:API — 재생 동시 성립+risk 원장=push-to-talk 완화).
- TTS·상시 청취(VAD)·PC 원격 구두(jkbridge chat 폭발) = 비-목표(v2).
- 캐논: Win 818/WSL 795(+2u 127 — #111 이후)/posix 304/폰 795 기대(+2u 증분) — 신설 계보 **2v**만 증분·기존 계보 등호.
- 커밋 계약 전부(명시 경로·IP 0건(-F)·push·amend 금지·트레일러)·빌드 ninja 3축·서브에이전트 스폰 금지.
- 폰 주소 인쇄 금지(자리표시 PHONE_HOST=<폰> — 서브넷 정찰 절차 원존)·폰 sshd/마이크 권한 = 사용자 완료 확인(2026-10-25).
