# 105 — 사용자 사용 환경·시나리오 원장 (2026-11-08)

사용자 요청("이번 기회에 사용자의 환경과 시나리오에 대해 한번 정리")으로 정산.
**이 문서는 라인 배치 판정의 상위 전제 원존** — PC 의존 판단(무인복구 leg 기각
— docs/phone-dex-target-report.md 후보 정산)을 비롯한 모든 배치 결정의 근거
문서. 세부 원문은 각 전용 리포트 승계.

## 1. 물리 환경

| 축 | 실물 | 역할 |
|---|---|---|
| 폰 | Galaxy Fold (q2q) — 커버 832x2268·내측 1768x2208 | **컴퓨터 본체** (일상 사용 축) |
| TV | RTK HDMI 1920x1080 | DeX 대상 표면 — 거실 배치 |
| PC | 개발 머신(Windows+WSL) | **개발 전용 — 사용 현장(룸)에는 존재 안 함** |
| 직장 | 삼성전자 타이젠 플랫폼 | 별도 과제 라인(Tizen 이식 원장 분리 확정) |

**핵심 제약(사용자 판정 원존)**: 현장 = TV+폰만. PC는 개발기 — 현장에 PC가
"있을 수 없다"(사용자 원문). 모든 기능 설계는 **폰 단독 폐곡** 기준.

## 3. 시나리오 3종

### A. 거실 DeX (주 시나리오 — 마일스톤 원존)
- 폰→TV DeX 도킹 → TV에 jkdesktop 풀스크린(아이콘 그리드 데스크탑 —
  DeX 표면 위계: TV=logical 2 가상 Desktop·앱 비가시 — 원존 원문
  docs/phone-dex-target-report.md).
- **제어 = 폰으로**: 콘트롤 앱(독립 chg.jkcontrol) MIC → STT →
  localhost:8091/talk → 라우터 3단(exact 즉발/패턴 열/LLM 턴).
  BACK·브라우저 개봉/닫기·앱 실행·창 목록·하루 정리 전부 구두.
- **부팅·복구 = TV 한 탭**: jkdesktop 죽어도 TV에 DeX 환이 남는다 →
  DeX 홈 JK 아이콘 한 탭 = 정식 복구("부팅은 TV 한 탭, 제어는 폰 구두").
  PC 무인복구 leg 기각 위 원존(재제안 금지).
- 트랙패드: 좌우 동시버튼 챠드 = 더블클릭 축(합성 규약 원존).

### B. 폰 단독 (이동 중)
- APK를 폰 화면(디스플레이 0)에서 직접 — 콘트롤 판/마이크도 같은 앱 내
  PhoneControlActivity로. DeX 없이 폰 화면으로 데스크탑 사용 가능.

### C. 개발 사이클 (PC가 있는 곳 — 현장 밖)
- PC 빌드(gradle/ninja) → adb 무선 install -r → 폰 실측(캡처+로그 원문) —
  **무선 연결은 페어링 상존(재발급 시 재페어 = 사용자 1회 터치)**.
- 폰 주소 매번 스캔/기록 금지 · git add -A 금지 · vplayer 테스트 영상 금지 ·
  사내 repo 외부 공개 금지 · permissions.json = 런타임 파일 · API 키는 폰
  내부 저장(민감값) — 기존 규약 전부 여기에 상존.

## 4. 시나리오 A의 유일 자연어 갭 (정산의 핵심 발견)

룸(현장)에서는 PC가 없다 → **LLM 릴레이(폰→PC ollama :11434)는 현장 밖**.
그래서 현장 자연어의 유일 경로 = **cloud 턴(API 키 — 폰 내부 저장 대기)**.

| 턴 종류 | 거실(무PC) | PC 개발 사이클 |
|---|---|---|
| exact 즉발 어휘 | 동작 | 동작 |
| 패턴 열(앱어·별명·조사 흡수) | 동작 | 동작 |
| 자유 발화 LLM 턴 | **cloud 턴 필요(API 키 대기)** | PC ollama 릴레이(T7 원존) |

→ **cloud API 키 준비 = 시나리오 A의 자연어 완성을 위한 유일 대기 결제** —
배치 가치가 PC 릴레이 보완 이상으로 올라간 상태.

## 5. 배치 판정 기준 (원존 승계)

1. 폰 단독 폐곡 우선 — PC 의존 leg 신설 = 구도 위반(기각 사례 1건 위).
2. 환경꾸미기 시간 최소·경험(STT 구두·DeX) 도달 가속.
3. 대기 중 폐곡 가능한 것은 전부 진행(멈춤 금지 — 사용자 상존 지시).
4. 정직 원문 계약 — PASS/FAIL 구분·가짜 성공 금지·결측은 -1류로 기록.
